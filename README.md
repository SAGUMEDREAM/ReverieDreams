# Gensokyo: Reverie of Lost Dreams

*Forgotten dreams don't vanish, they only drift somewhere else — and there is more than one Gensokyo. Everyone carries one.*

*There is more than one Gensokyo. It exists within everyone’s heart.*

A Touhou Project-inspired Minecraft mod: danmaku combat, new dimensions, fishing, cooking, and a custom content ecosystem.

## Compatibility

| Platform                | Status                       |
| ----------------------- | ---------------------------- |
| Fabric                  | supported                    |
| NeoForge                | supported                    |
| Polymer (server-side)   | Fabric only                  |
| JEI / REI               | supported                    |
| Polydex                 | needs the polydex2rei bridge |
| Bukkit + Fabric hybrids | not supported                |

## Features

- Reworked fishing
- Danmaku combat
- Custom workstations and factory blocks
- Moon and Dream World dimensions
- Cooking system, inspired by Mystia's Izakaya
- Built-in recipe viewer, no JEI/EMI needed
- Recruitable Touhou companions
- Crafting altars for progression

## Commands

| Command          | Description             |
| ---------------- | ----------------------- |
| `/touhou help`   | list commands           |
| `/touhou recipe` | open the recipe browser |
| `/touhou about`  | mod info and credits    |
