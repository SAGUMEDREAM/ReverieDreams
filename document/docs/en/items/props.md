# Tools and artifacts

| Item | Use |
|---|---|
| Boundary ofuda | Use on a block to open a two-way Gensokyo gap for 3 minutes, consuming one; use in Gensokyo to return to the recorded origin |
| Gap ball | Sneak-use to record/select destinations, then use on a block to open a gap |
| Dream pillow | Sneak-use on an Overworld bed; waking after sleeping in it enters the dream world |
| Crossing chisel | Use on a block to seek empty space on the other side, up to 16 blocks |
| Satori's eye | Use on a creature to inspect health, armor, effects and its target |
| Tengu camera | Use to photograph with blank photos available; sneak-use to adjust view |
| Fumo Sales License | Use on a villager to make a Fumo merchant; consumed |
| Quick Recipe Book | Save a recipe, then use on stocked kitchenware |
| Scarecrow | Use on a block to deploy; three sneaking empty-hand attacks recover it |
| Cheque | Sneak-use to deposit carried coins, minimum 10 mon; normal use to withdraw |

The **Time Stop Clock** pauses the world for about 5 seconds, with a 30-second cooldown; use again to release. Multiplayer behavior depends on permission and server policy, not the assumption that any player can freeze a server.

Violin, keyboard and trumpet use to play and sneak-use to select music. A note projectile held offhand enables their projectile behavior. NPC music work uses the server's configured NBS playlist.
