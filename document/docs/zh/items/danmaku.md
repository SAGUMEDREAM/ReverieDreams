# 弹幕、模板与强化

弹幕由**形状、颜色和实际属性**共同决定。形状创作模板、符卡模板和可发射的弹幕分别承担不同作用，同一 ID 下也可有不同组件款式。

## 制作路线

1. 获取**弹幕形状图纸**（原**弹幕创作模板**，`danmaku_recipe_creator` / `danmaku_shape_blueprint`），右键打开绘制界面。按[配方查询](../recipes)的形状图绘制已支持的轮廓；任意画一张图不代表会生成新弹种。
2. 打开**弹幕制作台**，将染料、弹幕核心、Power、Point 与带形状数据的**弹幕创作模板**放入对应格子。槽位判定支持真实的物品类型，不会因对象持有者问题拒收材料。
3. 结果出现后点击领取，材料按照配方数量消耗。染料和形状不同会产生不同结果；普通空白创作模板不能冒充指定形状。
4. 持有成品弹幕右键发射。没有无限属性时会消耗耐久，耗尽后该弹幕物品消失。射击存在弹种冷却。

配方图中“材料”对应带形状组件的创作模板；查看物品详情的具体组件和款式，可区分外观相同的模板。

## 用强化台调整弹幕

主槽放入可强化的弹幕，副槽放入材料，点击预览结果领取。每次消耗输入槽中的一个物品。

| 副槽材料 | 当前规则 |
|---|---|
| **符卡模板** | 替换轨迹模板，并同步该模板的轨迹配置 |
| **速度羽毛** | 实际速度 +0.25，结果必须 ≤2.5 |
| **黏液块** | 发射次数 +1，结果必须小于 3，因此此路径最多到 2 |
| **铁剑** | 伤害 +0.25，结果必须小于 5.5 |

达到边界后不再出现有效结果。配方库会列出运行时生成的强化操作，它们用于说明输入组合；最终数值继承你放入的弹幕，不能把列表图标当成固定成品。

强化台配方同步现已接入网络分包通道（chunking channels），即使配方与轨迹组合大量增加，也不会因突破原版 2 MiB 的 NBT 单包上限而导致玩家客户端进服异常断开。

## 轨迹算法与发射预算

* **16 种弹幕轨迹**：支持扇形（fan）、平视环形（ring_view）、水平环形（ring_horizontal）、球形（round）、花纹（pattern）、子弹（bullet）等 16 种参数化轨迹模板，在强化台可无缝写入弹幕属性。
* **单次发射预算限制**：所有由物品和 NPC 调用的弹幕发射均受到统一的 **64 发单次齐射预算限制**（`DanmakuVolleyBudget`），防止因单次巨量弹幕堆叠造成服务器卡顿或客户端渲染崩溃。

## 碰撞箱分型与星弹渲染

* **碰撞箱独立缩放**：
  * **大玉（Bubble）**：拥有放大的碰撞判定体积，弹速较慢，适合范围封锁；
  * **光球、音符、米弹**：弹速高、基础伤害适中，适合高频压制；
  * **弹丸（Bullet）**：注重直线高单发伤害；
* **星弹（Star）视向平滑旋转**：星弹引入同步的 2D 滚转角（ROLL angle），始终面向摄像机渲染（Billboard 广告牌效果），实现平滑的屏幕法向自旋，还原原作东方的星形弹幕视觉效果。

## 符卡与清弹

符卡右键释放卡中记录的弹幕。**Bomb** 使用后清除附近敌方弹幕并转成 Point，自身会消耗。姬海棠果的手机也有拍摄清弹用途；它们与月都枪械的实体弹匣不是同一套弹药系统。
