# 道具与探索工具

道具功能以当前游戏内说明和具体触发条件为准。下面是容易混淆的操作；点击图鉴可追查材料和用途。

| 道具 | 怎样使用 |
|---|---|
| 境界符札 | 右键方块开通往幻想乡的双向隙间；在幻想乡使用则返回来处。通道持续 3 分钟，消耗一张 |
| 隙间之球 | 潜行右键记录或选择目的地，再对方块右键开隙间 |
| 梦境枕头 | 潜行右键给床安装；在主世界睡该床，醒来后进入梦境 |
| 穿墙之凿 | 右键方块，尝试穿至另一侧空位，最多 16 格 |
| 觉之眼 | 对生物右键查看生命、护甲、效果及当前攻击对象 |
| 天狗相机 | 右键拍照，需要空照片；潜行右键调整视野 |
| Fumo 销售许可 | 对村民右键，将其转为 Fumo 商人，消耗许可 |
| 快速食谱 | 右键保存菜谱，对已经备料的厨具使用 |
| 稻草人 | 对方块右键放置测试伤害；潜行空手攻击三次收回 |
| 支票 | 潜行右键存入身上钱币，至少 10 文；普通右键兑回余额 |

## 时停钟

右键暂停世界约 5 秒，再次使用解除，冷却 30 秒。权限取决于服务器和当前游玩人数；多人环境需要管理员允许，不能以单人效果推断任何玩家都能冻结服务器。

## 乐器

小提琴、键盘、小号右键演奏，潜行右键选择曲目；副手持音符弹可配合发射音符弹幕。NPC 的演奏工作模式使用配置中的 NBS 播放列表，见[伙伴指南](../entities/npc-companion)。
