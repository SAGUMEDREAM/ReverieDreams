# 从这里开始

本 Wiki 对应 **Minecraft 26.1.2、模组 0.6.9+26.1.2、Java 25**。物品名称来自游戏语言文件；图鉴和配方来自本版本实际注册内容。服务器的数据包或配置可以改变玩法，请以你所在服务器为准。

## 安装与进入游戏

选择与整合包一致的 **Fabric 或 NeoForge** 版本，安装对应的模组文件及其声明的前置。Fabric 需要 Fabric API、Architectury；NeoForge 按该版本的依赖提示安装 Architectury、GeckoLib 等前置。不要把两个加载器的模组文件同时放入同一个实例。

普通模组游玩需要客户端与服务端版本匹配。Fabric 的可选 Polymer 扩展可用于向原版客户端提供资源包表现；它是独立的兼容部署方式，不能用来推断普通安装无需客户端模组。这里的攻略针对模组内容。

## 第一次游玩的路线

1. 先按原版生存建立工具、食物和安全住处。收集遇到的 **Point、Power、妖精材料、银矿和宝玉**，暂时保留；它们会进入不同制作配方。
2. 打开[物品图鉴](./catalog)搜索目标物品，点击查看“如何制作”和“获取记录”。每个配方都标明所需工作台、数量和材料组件；标签材料可以切换查看允许的物品。
3. 想做特色道具和角色卡，先建设[幻想乡祭坛](./blocks/altar)。想做远程弹幕，走[形状绘制 → 弹幕制作台 → 强化台](./items/danmaku)路线。
4. 想经营食堂，先完成[种植采集](./blocks/crops)、[烹饪](./blocks/cooking)和[酿造](./blocks/brewing)，再设置[夜雀钟与菜单本](./blocks/restaurant)。有顾客 NPC 并不等于店铺已经营业。
5. 取得角色卡后召唤并管理[伙伴 NPC](./entities/npc-companion)，准备工具、物资、工作区域和通路，再交给它自动工作。
6. 准备好补给和返回方式后，再探索[幻想乡、梦境和月球](./world/gensokyo)。

## 怎样读图鉴

“款式”会区分同一物品 ID 下的角色卡、弹幕模板、染色等实际数据。数量角标就是配方数量。祭坛图的中心是核心槽，外围顺序对应游戏界面。3D 预览可拖动旋转；料理详情可切换摆盘模型。

没有制作配方不代表只能从创造模式获得：物品还可能来自生物、作物、村民交易或其他交互。掉落记录会保留随机条件，不应当作必掉清单。界面占位和调试物品会明确标注，不能当成生存目标。
