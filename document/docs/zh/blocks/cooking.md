# 料理与厨具

烹饪分为 **煮锅、料理台、油锅、烧烤架、蒸锅** 五类。先查目标料理配方所标的厨具，换成另一种类型不会自动获得同样的菜谱。

## 做第一道菜

1. 把厨具放在有支撑的表面，右键打开界面。
2. 将配方要求的食材放入五个输入槽；留空的槽位可以以后用于额外食材。
3. 在界面显示的候选料理中选择要做的菜。相同材料可能匹配多道菜，必须点选产物才开始。
4. 等待完成提示，再打开厨具取出产物。开始后不要拆掉厨具或离开到区块不再运行的位置。

一次烹饪会从**每个非空输入槽取一个物品**，不仅是菜谱要求的基础材料。放进去的额外食材也会消耗，带容器的材料可能返还容器。当前厨具没有要求你额外塞入煤炭作为启动条件。

## 基础菜谱与额外属性

菜谱决定料理类型；额外食材可给料理增加食物属性。成品的显式属性会覆盖同类物品的默认属性，所以名称相同的两份料理不一定满足同一位顾客的偏好。

不相容的属性组合可能成为**黑暗料理**。给顾客做菜前，先查看成品提示和偏好；不要把额外食材当成无条件增强。图鉴展示的是默认菜品属性，实际加料结果以游戏中那份成品为准。

## 需要多久

配方卡标记的是基础秒数。普通界面烹饪当前固定额外计入 **1.25 秒**；快速食谱路径则额外计入“菜谱基础食材种数 × 0.25 秒”。之后除以厨具的每 tick 进度倍率：

| 厨具系列 | 进度倍率 | 随机失败率 |
|---|---:|---:|
| 普通 | 1.00 | 0 |
| 夜雀 | 0.75 | 0 |
| 超 | 1.05 | 0 |
| 极 | 1.10 | 0 |
| 核能 | 1.50 | 40% |

夜雀系列当前代码每 tick 推进 0.75，所以在本版本中耗时更长；不能仅根据系列名字判断速度。属性冲突导致的失败与表中的厨具随机失败是两种判定。

## 快速食谱与摆盘

**快速食谱**右键选择并保存一道菜，再对对应厨具使用。厨具里仍要备齐材料，书不会免费生成食物。这个入口与手动选菜的处理路径不同，想通过额外食材调整属性时先用普通界面确认结果。

料理可作为食物使用，支持摆盘的料理还可以放置；图鉴详情中的“查看摆盘模型”展示它成为方块后的样子，不用物品贴图冒充盘子模型。
