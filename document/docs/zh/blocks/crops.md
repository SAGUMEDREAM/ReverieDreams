# 种植、林木与食材采集

模组作物与林木提供料理、酿造及建筑材料。获取种子后在耕地或水田种植，保证充足光照（亮度 ≥9）并等待成熟；支持骨粉催熟。

## 种植和收获

| 作物 | 最大生长阶段 |
|---|---:|
| 辣椒、黄瓜、红豆、西兰花、大豆 | 4 |
| 葡萄、洋葱 | 5 |
| 香椿、白萝卜、红薯 | 3 |
| 番茄 | 3 |

对模组成熟作物**空手右键**，会掉落收成并保留为该作物的幼苗状态；未成熟时不会触发该收获方式。直接破坏作物依然按照战利品表掉落对应产物。

* **作物逆向分解配方**：收获的模组农产品（辣椒、黄瓜、葡萄、洋葱、红豆、番茄、香椿、白萝卜、红薯、西兰花）均可放入工作台无序合成，直接**反向拆解为 2 粒对应种子**（自播大豆除外）。在缺少种子时可快速将收成扩繁。
* **藤蔓野外采集**：手持任意锄破坏原版藤蔓（`minecraft:vine`）时，有 **10% 概率直接掉落葡萄**，为尚未找到葡萄种子的探险初期提供稳定的水果来源。

## 水田与耕地

**水田**是带有灵力水源的特化耕地，持续保持湿润状态，**绝不会因干涸或生物踩踏而退化为泥土**，破坏后掉落普通泥土。水田适合长期集约化种植水稻与各类模组作物。

## 枫树与特化林木

主世界森林群系中生成三种特化枫树生态：

* **枫树树种**：包括 **鸡爪槭（Iroha Maple）**、**板屋枫（Itaya Maple）** 与 **羽团扇枫（Hauchiwa Maple）**。
* **完整木质建材套件**：每种枫树均具备完整的原木、树皮、去皮原木、去皮树皮、树叶、树苗、木板、楼梯、台阶、门、活板门、栅栏、栅栏门、按钮与压力板。
* **自然叶片落叶**：枫树树冠遵循原版树木距离衰落机制，在支撑原木被伐倒后正常落叶并掉落树苗及落叶地被。

## 动物、鱼与交易食材

肉类、水产、调味料不全来自作物。查看各食材的获取记录：部分会出现在村民交易和生物战利品中。NPC 农作模式在收割后仅补种原作物种子，详见[伙伴工作](../entities/npc-companion)。
