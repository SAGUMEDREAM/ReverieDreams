# 幻想乡祭坛

祭坛制作道具、材料和角色卡。先用[配方查询](../recipes)查到祭坛方块自身的工作台配方，再搭建下面的结构。

## 3D 搭建预览

拖动查看不同方向，或切到“俯视”核对位置；在“查看层级”中单独查看底层、中层和顶层。点选方块可读出它相对于祭坛的坐标。准备 **1 个幻想乡祭坛、16 个去皮绳文杉、8 个被祝福的绳文杉柱**。

## 搭建八根柱子

以祭坛方块的位置为原点，东为 +X、南为 +Z。八根柱子的水平偏移如下；每根柱子与祭坛底部同高的两层都是 **去皮绳文杉**，第三层是 **被祝福的绳文杉柱**。手持纸对去皮绳文杉使用可将其祝福。

| X | Z |
|---:|---:|
| 0 | -4 |
| -3 | -3 |
| 3 | -3 |
| -4 | 0 |
| 4 | 0 |
| -3 | 3 |
| 3 | 3 |
| 0 | 4 |

柱子上下位置以祭坛所在 Y 为准：Y、Y+1 为去皮绳文杉，Y+2 为被祝福的绳文杉柱。普通原木、其他木种和看起来相似的装饰块不能替代这些指定方块。

## 放入材料并启动

普通右键打开祭坛界面。九格布局为：

| 外围 0 | 外围 1 | 外围 2 |
|---|---|---|
| 外围 3 | **核心 8** | 外围 4 |
| 外围 5 | 外围 6 | 外围 7 |

照 Wiki 配方图把核心放在中央、其他材料放在外围。外围按照界面逐行排列。材料数量需要满足配方；要求有组件的角色卡或模板时，普通空白物品不能代替。

关闭界面后，**潜行右键祭坛**检查结构并尝试合成。成功会消耗所需材料，产物位于核心槽；核心剩余物会返还或掉落。Point、Power 在这里是实体材料，按照格子中的数量投入。

## 无法制作时

先查每根柱子的坐标与三层材料，再检查核心槽、外围空格、物品数量和具体款式。别把“绳文杉原木”“去皮绳文杉”“被祝福的绳文杉柱”混用，也别把外围八格当作顺时针排列。
