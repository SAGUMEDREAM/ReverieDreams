# 餐厅营业：夜雀钟与菜单本

餐厅以**夜雀钟**作为营业控制，以**菜单本**限定可点的料理与饮料。原版钟不能代替夜雀钟。将 NPC 切到顾客模式之前，先完成店铺设置。

## 开第一家店

1. 放置夜雀钟和菜单本。方块会记录放置者，通常由所有者或创造玩家设置。
2. 右键菜单本，在“料理”“饮料”两个分类里各勾选至少一种有效条目。点击的是菜单设置，不会凭空生成食物，也不会拿走背包里的样品。
3. 菜单支持搜索、分页和仅显示已选项；料理、饮料分别最多 128 项。
4. **潜行右键夜雀钟**打开设置，绑定附近的菜单本。钟默认水平范围为 8，可在打烊时调为 2～16；垂直范围为 8。菜单本必须在范围内，一本菜单不能同时绑定多家店。
5. 给顾客准备座位，设置其工作地点在店铺范围内，并备好实际食物饮料。
6. **普通右键夜雀钟**切换营业。缺少有效绑定、料理或饮料时，不能开始营业。

## 点单与打烊

营业中的顾客从本店菜单允许的内容点单。菜单本只控制点单范围，不能代替厨具、酒桶和库存。顾客的工作点必须处于营业钟的服务范围，NPC 也需要能够走到座位。

普通右键钟即可打烊：停止接受新单，已经接受的订单按原记录处理。菜单被改动后，已接订单使用接单时的菜单记录，避免半途换菜单让订单变成另一道菜。

拆掉或替换钟、菜单本，或者改变绑定，会使原设施失效；不要把同位置放回的新方块当成原店铺。设施区块卸载时相关服务会等待重新可用。

## 通用客人与专属客人

角色身份与顾客档案是两回事。**有当前角色专属顾客数据**才使用其预算、偏好、厌恶与评价规则；没有覆盖到的角色进入**通用顾客**规则，不会借用其他角色的专属档案。两类都必须依托有效营业的店铺，点单都受菜单约束。

顾客坐下进入点单后，空手普通右键可询问订单；手持料理或饮料普通右键分别交付，每种取一个，两类交齐后结算。潜行交互不会执行交单。额外属性会影响评价，专属客人的喜恶需要看其偏好说明；不能仅看菜品名称。非进食期间的换单倒计时与交单后的进食时长分别由两个[配置项](../settings)控制。

## 顾客不点单时

依次检查：是夜雀钟吗 → 已营业吗 → 钟和菜单本互相绑定吗 → 两类菜单都有有效条目吗 → 工作点在范围内吗 → 座位能到达吗 → 上一次进食结束了吗。先把这些条件满足，再排查菜品选择。
