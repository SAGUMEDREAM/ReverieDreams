# 月面信号塔

月面信号塔是一处可修复的通信设施。高地和玄武月海中自然生成的信号塔包含维护间、检修梯道、接收盘、维修物资桶和磁石控制台。

## 修复

进入维护间，右击室内的磁石打开控制台，依次安装零件：

| 阶段 | 所需零件 | 工作台合成方式 |
| --- | --- | --- |
| 恢复供能 | 月面供能单元 ×1 | 四角放铁锭、四边放红石、中心放石英 |
| 接通信号 | 月面信号线圈 ×1 | 八个铜锭围住中心铁锭 |
| 校准接收器 | 月面校准晶体 ×2 | 四个石英上下左右围住铁锭，一次得到两个 |

维修桶固定提供一个供能单元和少量物资。研究所、补给遗址等原有月面宝箱也可能出现维修零件；合成提供另一条获取途径。每一步只消耗该阶段所需数量，零件不足不会部分扣除。

修复进度由同一世界中的玩家共享，退出、重启服务器后保留。最后一步点亮控制台地灯，并向完成修复的玩家提供一枚指南针；同一座塔不会重复发放。

## 定位和导航

修好后选择“扫描附近信号”。信号塔搜索水平距离 4096 格以内的三类目标：

- 研究所：已有的月面研究所。
- 补给遗址：已有的月面废弃建筑，宝箱可搜集补给和维修件。
- 异常隔离设施：已有的隔离池结构。

扫描按批次运行，关闭菜单也会继续，完成后重新右击控制台查看结果。每类显示最近一处目标的 X/Z 坐标和到信号塔的距离；范围内没有该类目标时会明确提示。每座塔每 60 秒可重新扫描一次，结果会保留在存档中。

主手持有指南针，再选择某个目标即可导航。若手中有一叠指南针，只绑定其中一个，其余不变。导航指南针仅在月球维度指向该目标，目的地本身不需要放置磁石。

## 旧存档和建筑备份

新建筑模板只用于新生成的信号塔，更新不会自动拆改旧区块。旧自然生成信号塔仍沿用原来的结构范围，在范围内放置磁石也可作为控制台使用。普通月面磁石、玩家自行搭建的塔或单独用结构方块放置的模板，不会被当作自然信号塔。

原建筑的完整 NBT 备份位于项目的 `tools/moon-signal-tower/backups/2026-11-05/`。其中 `signal_tower.nbt` 是替换前的原塔，另外保留研究所及废弃建筑副本；后两种建筑没有重建，只扩充了它们使用的战利品表。

如要恢复原塔模板，将备份的 `signal_tower.nbt` 复制回 `common/src/main/resources/data/reverie_dreams/structure/` 后重新构建模组。恢复模板只改变以后生成或放置的建筑，不会自动改动已有区块。
