# NPC 伙伴与工作

## 召唤、状态与背包

对方块使用有效的**角色卡**，在 Dialog 中点击角色文字，再点击召唤文字确认。分组卡只提供对应角色；服务器开启自由选角规则时可从所有已注册分组选择。空白卡与带分组组件的卡不是同一种数据。

对自己有管理权限的 NPC **空手潜行右键**打开背包菜单，管理装备、状态和工作模式。未认主的 NPC 可喂食 #reverie_dreams:role_tame_food 标签内食物尝试结交，每次成功概率 40%，不保证一次成功。先把状态设为**工作**，再选择工作模式；仅切换工作模式不会替代工作状态。跟随、自由行动、不移动、潜行、坐下分别用于日常控制。

工作以记录的工作点为中心，默认水平 8、垂直 8 格，可由服务器配置调整。货物使用独立的 **18 格**区域，主副手与装备不是杂物箱。默认自动物流在货物达到 14 格占用时尝试卸货；容器要在范围内且有可行走通路。

## 各工作需要什么

| 工作 | 玩家准备 | 运行要点 |
|---|---|---|
| 战斗 | 合适武器、护甲，枪械准备兼容弹匣 | 可巡逻；目标优先级受配置控制 |
| 农作 | 成熟作物、对应种子、货物空间 | 只重种原来那种作物，不乱换种子 |
| 繁殖 | 动物对应繁殖食物 | 默认保留 2 份食物，区域动物上限 32 |
| 剪羊毛 | 可用剪刀、可到达的羊 | 检查羊是否有毛及货物空间 |
| 熔炼 | 原料、燃料、熔炉和接收箱 | 先检查配方、燃料与输出是否堵塞 |
| 箱子分类 | 箱子/桶、分类样品或展示框 | 见下文规则；给食物与工具留储备 |
| 演奏 | 本地 NBS 曲目和播放列表 | 服务器配置音量、范围、循环 |
| 蜂产物采集 | 满蜂巢、剪刀或玻璃瓶、默认要求的烟 | 可选择蜂蜜、蜜脾或自动 |
| 钓鱼 | 鱼竿、合适水面、站立位置 | 留出收鱼的货物槽 |
| 顾客 | 营业中的店铺、菜单、座位 | 按[餐厅指南](../blocks/restaurant)准备 |

与其他模组联动的摇柄工作仅在对应兼容内容存在时出现。NPC 暂停工作时，先看其状态说明和物资，避免连续改模式掩盖缺料或无法寻路的问题。

## 用物品展示框给仓库分类

在容器上挂装有样品的展示框。**每旋转两次**切到下一组模式，八个旋转位置分成四组：

| 旋转值 | 模式 | 规则 |
|---|---|---|
| 0、1 | 同物品 | 收与样品相同 ID 的物品 |
| 2、3 | 同分类 | 按服务器允许的标签分类，例如原木、木板、矿锭 |
| 4、5 | 输入箱 | NPC 从这里取走待分类物品 |
| 6、7 | 溢出箱 | 接收其他目标无法容纳的物品 |

默认放入样品就是“同物品”。同一容器的多个展示框需要使用同一种模式；混用会造成规则冲突。分类选择与合并堆叠不同：不同组件的物品不会被强行合并。无展示框的容器按已有内容和“允许占用空箱”配置处理。

默认分类会保留 16 份食物和 1 份工具储备。容器已满、通路不通或规则冲突时，先处理问题，NPC 不会因此把装备当作普通货物搬走。

## AI 自然语言互动与持久技能任务

当服务端配置了支持 Tool Calls 的 AI 服务时，主人可以直接在 NPC 对话界面使用自然语言下达实际的世界互动指令。所有动作均在服务器主线程重新校验权限、距离（限 32 格内）与存活状态。

### 自然语言动作指令

* **环境观察（`observe`）**：返回自身坐标、周围 8 格可见实体、天气、手持与背包物品，以及周围 32 个农田、设施与容器状态。
* **跟随与待命（`follow` / `stay`）**：切换跟随主人或原地等待。
* **寻路移动（`move_to`）**：在自身 16 格内寻路步行前往指定坐标，不传送、不加载未加载区块，最长执行 20 秒。
* **原地工作（`work`）**：将当前位置设为原点并启动指定工作。

### 持久技能任务与数量目标

通过技能系统（`start_skill` / `task_status` / `cancel_task`），NPC 可以执行持久化的单项工作并跟踪数量目标：

* **数量核验机制**：支持为 `farm`（农作）、`fish`（钓鱼）、`shear_sheep`（剪羊毛）、`harvest_honey`（采蜜）设置目标物品与数量（1～1024）。只有**真实工作产出事件**且 NPC 背包实际持有所需数量才会被累计为完成进度；旧存量或玩家赠予不会被冒算。
* **熔炼与繁殖**：`smelt` 支持成品数量目标，按批次投料；`breed_animals` 仅在双亲成功生成动物幼体时计入有效次数。
* **离线保护**：主人离线、跨维度或离开超过 32 格时，技能任务自动暂停，待主人返回后恢复。

### 容器授权与物流存取

* **容器授权（`authorize_container`）**：主人在容器 6 格内且 NPC 在 16 格内时可授权指定箱子或木桶（最多 8 处）。
* **存取物资（`deposit_items` / `withdraw_items`）**：NPC 自动走至已授权容器 3 格内进行安全存取。

### 角色特质与伤势保护

* **性格特质**：全 110 张角色卡具备细分性格反馈与工作偏好（如妖梦偏好园艺、咲夜偏好分类整理、荷取偏好熔炼）。
* **生命保护回差**：NPC 在工作中受到伤害时，通用策略在生命低于 25% 时主动暂停工作、回升至 40% 后恢复；谨慎型角色在低于 50% 时暂停、达 65% 后恢复。

## 回收与再次放出

对自己拥有的伙伴使用空白**魂符**可将其回收为包含角色数据的归档物品；手持有效归档对方块右键可重新放出。角色归档物品带有所有权信息，仅归属玩家可再次放出。
