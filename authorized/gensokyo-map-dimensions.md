# 幻想乡地图数据-维度授权说明

## 概述
本模组幻想乡维度所使用的地形数据，参考并基于大猫凌霜制作的幻想乡等比例地图工程，通过高度图与合成图推理生成。

该地图采用固定地图的形式，幻想乡各个区域之间的相对位置保持一致，并非随机生成的世界地形。

地形数据的使用已获得原作者大猫凌霜的授权。特此注明原作者及相关作品来源，感谢原作者的创作与授权。
