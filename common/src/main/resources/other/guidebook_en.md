## 1. Welcome & Overview

Welcome to **Reverie Dreams**! This guide will help you get started with the mod.

> **Current Document Version:** `2026.5.4`

This mod is a magic and adventure mod inspired by various excellent Touhou doujin mods and games, adding a wealth of Touhou Project content to modern Minecraft.

## 2. Basics

### 2.1 Getting Started

To begin playing, you first need to craft the **Gensokyo Altar**, which is the starting point for all crafting in this mod.

**Core Crafting Materials:**

| Material | Description |
|----------|-------------|
| 🔮 **Power** | Basic crafting material, obtained by defeating monsters or fairies |
| 🔵 **Point** | Basic crafting material, obtained by defeating monsters or fairies |

**Step 1: Craft the Gensokyo Altar**

Through the altar, you can craft the following key items:
- 🌿 **Horai-dama no Eda**
- ⚔️ **Gungnir**
- 🎋 **Hakurei Cane**

> 📖 For more recipe information, consult Polydex or REI.

### 2.2 Gensokyo Altar Setup

The Gensokyo Altar is the **most important crafting workbench** in this mod. Most items require it for crafting.

#### Structure Requirements

The altar supports a crafting recipe structure consisting of **nine items**. To make the altar functional, the following structure must be built:

```
# # # # O # # # #
# O # # # # # O #
# # # # # # # # #
# # # # # # # # #
O # # # A # # # O
# # # # # # # # #
# # # # # # # # #
# O # # # # # O #
# # # # O # # # #
```

**Structure Setup Notes:**

- 🪵 **Pillar Material:** Use **Stripped Spiritual Log**. This type of tree can usually be found in the **Savanna** biome.
- 📜 **Top Layer Blessing:** Use **Paper** and **right-click** on the top layer logs to bless them.
- ✂️ **Cancel Blessing:** Use shears and **right-click** to remove the blessing.
- 🖐️ **Complete Crafting:** After confirming the recipe is correct, **empty hand + Shift + right-click** the altar to complete the synthesis.

### 2.3 Danmaku Guide

**Danmaku** refers to the bullet-hell mechanics commonly seen in STG games, where a dense mass of projectiles creates complex attack patterns. In this mod, "danmaku" follows the same concept.

#### Danmaku Crafting

Players need to use the **Danmaku Crafting Table** to craft danmaku.

**Material Layout:**

| Material | Amount |
|----------|:------:|
| 🎨 Any Dye | ×4 |
| ⚙️ Danmaku Core | ×4 |
| 🔮 Power | ×35 |
| 🔵 Point | ×35 |
| 📝 Danmaku Recipe Creator | ×1 |

#### Danmaku Shape Configuration

The **Danmaku Recipe Creator** is a key tool for configuring danmaku shapes, and is an indispensable part of crafting danmaku. Players can **right-click the template** to construct danmaku patterns in a dot-matrix format.

#### Danmaku Enhancement

All danmaku can be upgraded at the **Strength Table**. The currently defined upgrade materials and their effects are as follows:

| Upgrade Material | Effect |
|-----------------|--------|
| 🗡️ Iron Sword | Increases danmaku damage |
| 🟩 Slime Block | Increases projectiles per shot |
| 🪶 Speed Feather | Increases danmaku fire rate |
| 📜 Spell Card Template | Sets danmaku trajectory |

### 2.4 Fumo Plushies

**Fumo (ふもふも)** refers to the Touhou Project plushies produced by the Japanese company Gift, based on character designs by the doujin circle ANGELTYPE.

**Key Features:**
- 🧸 Sitting pose
- 😶 Signature blank expression (ᗜˬᗜ)
- 🌸 Soft plush texture
- 🎨 Licensed, exquisitely crafted Q-shaped design

#### How to Obtain

- Most Fumo plushies can be obtained in **survival mode through relatively expensive trades**.
- Players can only obtain Fumo by trading with **Fumo Merchants**.
- A Fumo Merchant's trade inventory **changes daily**.

#### Fumo Merchant

Using a **Fumo License** on a villager (right-click) will transform them into a Fumo Merchant.

#### Fumo Features

- Once placed, a Fumo will **automatically face the player's current position**, supporting **16 directional orientations**.
- Right-clicking a placed Fumo block produces the corresponding **Fumo sound**.

### 2.5 Role Partners

**Role Partners** are companion entities in this mod, functioning similarly to the maid units in the Touhou Little Maid mod.

#### Core Functions

| Function | Description |
|----------|-------------|
| 🎒 Inventory | Has an independent item storage space |
| ⚔️ Combat | Can assist the owner in battle |
| 🛠️ Work | Can execute certain work commands |
| 💬 Interaction | Supports dialogue and various interactions |

#### Taming Method

Each Role Partner needs an owner. Players can tame them and establish a master-servant relationship by **feeding them cake**.

#### Summoning Method

In survival mode, players can craft various **Touhou Project Role Cards** at the **Gensokyo Altar** to summon the corresponding Role Partner.

#### Revival Method

When a Role Partner dies, it drops a **Role Archive**. Players can place this item in the **Gensokyo Altar** and surround it with **two rings of diamonds** in the recipe to resurrect the corresponding character.

#### Controls

| Action | Effect |
|--------|--------|
| 🖱️ Right-click | Trigger daily dialogue |
| Shift + Left-click (empty hand) | Stop attacking target |
| Shift + Right-click | Open inventory |

### 2.6 Mystia's Izakaya (Touhou Cooking)

*Mystia's Izakaya* is a Touhou Project fan game, and this mod introduces it as an independent gameplay system.

#### System Overview

This system adds:
- 🥬 Ingredients from the original game
- 🍳 Prepared dishes
- 🍶 Alcoholic beverages
- 📖 Cooking recipes
- Adjustments to some vanilla Minecraft drops

#### Ingredient Sources

| Source | Description |
|--------|-------------|
| 🌾 Crops | Most ingredients have corresponding crop sources |
| 📦 Chests | Some seeds can be obtained from opening chests |
| 🎣 Fishing/Foraging | Seafood must be obtained by fishing or foraging |

Each food item has different **Tags**, and different Tags grant different effects to the food.

#### Kitchen Tool System

The cooking system has **five typeInstance** of kitchen tools, each with an **upgraded version**:

| Tool | Purpose |
|------|---------|
| 🥘 Cooking Pot | Basic cooking |
| 🔪 Cutting Board | Ingredient processing |
| 🍳 Frying Pan | Pan-frying |
| 🥩 Grill | Grilling |
| 🥟 Steamer | Steaming |

> ⚠️ **Dark Cuisine:** When recipe inputs are inappropriate or conflicting tags occur, **Dark Cuisine** may be produced.

> 💡 Some recipes support equivalent substitutions using items from other mods compatible with this mod. All cooking recipes can be looked up via the mod's recipe manager or the Mystia's Izakaya wiki.

> 📖 [View Kitchen Tool Recipes and Cooking Recipe List]

#### Alcohol System

Most alcoholic beverages can be obtained by trading with the **Bartender**.

**Beverage Features:**
- 🍶 Drinking provides various effects and buffs
- 🔄 The available beverage selection may change daily
- ✅ **Permanent Beverages:** Green Tea, Fruity High Ball, Fruity Sour, and Qi always appear in the sales list

**Bartender Job Conversion:** Players can right-click on a villager while holding a **Barrel** to convert them into a Bartender.

## 3. Story — Exploration Records

### 3.1 Outer Shrine

**【Exploration Record #01】**

I discovered this shrine around dusk.

It's not conspicuous. No approach lanterns, no row of torii gates — just a clearing in the woods, standing there abruptly. Unmarked on any map, surrounded by no signage, as if it was never meant to be found.

But strangely enough — it doesn't look abandoned. The stone steps have been cleaned, moss growing only at the edges. The water basin still holds traces of yet-to-evaporate water. The offertory box before the main hall is unlocked, its wood grain polished shiny from repeated touching.

It seems… someone still lives here.

---

**【Exploration Record #02】**

I met the old man on the second morning.

When he emerged from behind the side hall, I barely heard his footsteps. Simply dressed, moving slowly but not sluggishly.

He glanced at me — no surprise, no questions. Just nodded, then continued what he had been doing: sweeping fallen leaves.

I tried to talk to him.

He didn't say much. His answers were simple, almost as if he was deliberately avoiding certain topics.

> "Has it always been like this?"
> "More or less."
> "Is there anyone else?"
> "No."
> "You're alone?"
> "Mm."

The conversation ended there. He had no intention of continuing.

---

**【Exploration Record #03】**

I started paying attention to the shrine's details.

The offerings on the altar were simple — mostly ordinary food, occasionally some less common items. The ash in the incense burner was neatly arranged, suggesting the incense had never truly stopped.

The side hall stored old items. Mostly broken utensils, faded fabrics, and some objects whose purpose I could no longer identify. They were well-preserved — not like abandoned things, but more like things deliberately kept.

I asked the old man about their origins. He glanced at them but didn't answer. Just said:

> "What's meant to stay, stays."

---

**【Exploration Record #04】**

Time flows strangely here.

Not stagnant, not accelerated. More like… stretched.

The days are quiet, almost no sound from the outside world. No lights at night, only the occasional wind passing through. But no matter when I come, the shrine maintains a state of "just having been tended to."

I tried arriving earlier. The old man was already sweeping. I tried leaving later. He was still there.

It seems he is always here.

---

**【Exploration Record #05】**

I asked him why he stays.

He paused in his work, thought for a while.

> "Someone has to be here."
> "Why you?"
> "Just happened to be me."

His tone was calm, as if stating the most ordinary thing.

Then I asked: "What if no one ever comes again?"

He didn't answer immediately. After a moment, he leaned his broom aside and said:

> "It would be the same."

---

**【Exploration Record #06】**

As I left, I looked back once.

The shrine stood there, quietly. The old man was no longer in sight — I don't know which side hall he had returned to.

But I knew — this place will not become ruins.

At least, not while that person is still here.

Record ends here.

### 3.2 Mini Bar

**【Record: An Unnamed Bar】**

This place isn't marked anywhere.

I stumbled upon it by night. I was just walking along a path when I spotted a dim yellow light in the distance. I assumed it was an ordinary house. On closer approach, I realized it was a very small bar. No sign at the door. The windows were half-shuttered, warm light spilling out along with snatches of conversation.

The bell rang as I pushed the door open.

---

**【Record: Inside the Bar】**

The space was even smaller than I'd imagined. The counter took up most of it, with a few tables scattered around.

Not many customers. No one was being loud. Some whispered in conversation, others simply drank in silence. The atmosphere wasn't lively, but it wasn't cold either.

The kind of place where — once you sit down, you're tacitly allowed to stay.

---

**【Record: The Drinks】**

The liquor here is special.

The menu listed names I couldn't understand, with no recipes indicated. I ordered one at random, and the flavor was surprisingly complex. Not simply "good" — more like… carrying an indescribable feeling.

Some drinks lifted your spirits. Others made you unconsciously quiet down.

I tried asking about the drinks' origins.

The answer I got was:

> "Just some ordinary recipes."

---

**【Record: The Owner】**

The owner stood behind the counter the whole time.

Hard to tell his age. His tone was casual, but you always felt he knew more than he let on.

Whenever I mentioned certain rumors, he'd pause for a moment, then smile and change the subject.

> "These names don't sound like things from around here."
> "You've been to many places?"
> "You could say that."
> "And these drinks?"
> "Picked them up along the way too."

He said it all so lightly. But I wasn't sure if it was the truth.

---

**【Record: Details】**

There were decorations on the walls.

Some were ordinary drinking vessels. Others looked like they didn't belong in a place like this. I tried to study one of them a little longer.

The owner noticed.

> "Don't mind those. Just old things."

---

**【Record: Leaving】**

I didn't stay long.

When I left, the owner didn't try to keep me. Just nodded, as he would to anyone leaving. The moment the door closed, the light was sealed behind me.

When I looked back — the lamp seemed dimmer than before.

I didn't go back in to check.

---

**【Afterword】**

Later, I tried to find this place again.

I couldn't.

---

### 3.3 Abandoned Altar

**【Exploration Record: Unmarked Ruins】**

I found it in an area almost devoid of human traces.

At first, it was just an unusually flat stretch of ground. Too orderly compared to the surrounding wilderness. Following the trail forward, I came upon this altar.

---

**【Structural Observation】**

It was clearly man-made.

The stone arrangement followed an obvious pattern, with a central area meant for placing items. The surrounding structures weren't randomly piled either — more like a construction designed for ceremonial purposes.

But now — everything has been abandoned.

Dust covers the surface, almost entirely obscuring the original colors. Vines creep along the edges, tightly gripping parts of the structure. Some areas even show signs of minor damage.

It hasn't been used in a very long time.

---

**【Remains】**

There's still a chest next to the altar.

Not locked.

The contents aren't neatly arranged, but neither have they been completely ransacked. Some materials have rotted or lost their use, but others are still identifiable — even usable.

These items seem to have been left in a hurry. Not stored deliberately — more like… there wasn't time to take them.

---

**【Preliminary Assessment】**

Based on the structure and the remnants, this altar was originally meant to serve some function.

But now, it's no longer active.

I tried placing some materials back in position. No reaction. Perhaps key steps are missing, or… specific conditions are required.

---

**【Record】**

Before leaving, I surveyed the surroundings again.

No other obvious traces. No footprints, no signs of recent activity.

Just forgotten, like this.

---

**【Conclusion】**

This altar might still be reactivated.

But as of now, I don't have enough information to do so.

I decided to leave, for now.

(Record interrupted)

### 3.4 Abandoned Torii

**【Brief Record】**

A solitary torii gate was discovered in an open field.

Its structure is aged, covered in vines and signs of weathering. The original colors are almost entirely obscured, leaving only a mottled outline.

No shrine around it, no paths leading to it. Not even signs that any other structures once existed nearby.

It just stands here, alone.

Like a boundary — left behind.

### 3.5 Cherry Blossom Mound

**【Exploration Record】**

I paused for a moment beneath a cherry blossom mound.

It was much quieter here than its surroundings. When the wind passed, it carried tiny petals, but soon settled back into stillness. The ground showed no clear signs of disturbance — it seemed no one had visited in a long time.

But it wasn't "empty."

A faint trace of spiritual energy lingered in the air — weak, yet steadily present. Not something newly generated, but more like an accumulation left behind over a long period.

I tried to find its source.

No obvious devices or structures. No identifiable ritual traces. The spiritual energy seemed dispersed throughout the environment — clinging to the soil, tree roots, even the fallen petals.

Perhaps this isn't something "currently happening." It's more like… something once existed here.

The exact cause cannot be confirmed at this time. Recorded here for future investigation.

### 3.6 Bamboo Forest BBQ Stall

**【Exploration Record】**

I found this place while lost.

Deep in the bamboo forest, no one should stay for long. Directions are easily confused, paths are unstable. But in a place like this, a small BBQ stall appeared.

The setup was simple. Wooden racks, charcoal tools, neatly arranged ingredients. Everything looked like it was in normal use.

The problem was — there was no one here.

No footsteps, no traces of departure. The charcoal had gone out, but the smell of recent use still lingered. The ingredients on the counter were perfectly fresh, as if just prepared.

I didn't stay long.

---

**【Supplementary Record】**

Over the following days, I tried approaching this area again at night.

From a distance, I could see a faint glow — like someone lighting charcoal.

But when I actually got close —

It was still empty.

The stall remained in the same state, as if it "opens for business" every night.

Its mode of operation remains unconfirmed.

### 3.7 Bamboo Forest Hut

**【Exploration Record】**

A small hut was discovered deep in the bamboo forest.

Seen from afar, a faint light emanated from inside. In this environment where one can easily lose their way, such a light source stood out conspicuously. Outside the hut was a small pond — the water surface calm, with a few lotus leaves growing on it in good condition, as if carefully tended. But there were no clear signs of activity nearby.

The path leading here had become blurred. Fallen leaves and new vegetation covered everything, making the original road nearly indistinguishable.

Yet, the place didn't feel abandoned. Whether it was the plants in the pond or the light persisting from within the hut, everything maintained a subtle sense of "vitality."

I didn't enter the hut. I observed only from the outside before leaving.

This place seems to be continuously maintained by some means.

---

### 3.8 Nether Hot Spring

**【Exploration Record】**

A hot spring was discovered in a low-lying area.

Steam continuously rose from the water's surface, the temperature noticeably higher than the surrounding environment. The spring water wasn't murky — on the contrary, it was remarkably clear. At first glance, it appeared to be an ordinary natural hot spring.

Until I noticed the arrangement around it.

Several candles were scattered around the spring's edge. Some had burned out completely, leaving only solidified wax; others were still burning slowly. The flames were unsteady, flickering under the interference of the steam, yet never going out.

Not a single trace of anyone was found.

These candles didn't seem randomly placed — more like… traces deliberately left behind.

I didn't stay any longer.
