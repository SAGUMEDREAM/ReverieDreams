### 2.1 入门指南

要开始游玩，首先需要制作 **幻想乡祭坛（Gensokyo Altar）**，它是本模组一切合成的起点。

**核心合成材料：**

| 材料 | 说明 |
|------|------|
| 🔮 **Power（灵力）** | 基础合成材料，可通过击杀怪物或妖精获得 |
| 🔵 **Point（点）** | 基础合成材料，可通过击杀怪物或妖精获得 |

**第一步：制作幻想乡祭坛**

通过祭坛，你可以制作以下关键物品：
- 🌿 **蓬莱玉枝（Horai-dama no Eda）**
- ⚔️ **冈格尼尔（Gungnir）**
- 🎋 **博丽玉币（Hakurei Cane）**

> 📖 更多配方信息请查看 Polydex 或 REI。

### 2.2 幻想乡祭坛摆放

幻想乡祭坛是本模组中**最重要的合成工作方块**，大部分物品都需要通过它进行合成。

#### 合成结构要求

该祭坛支持由**九种物品**组成的合成配方结构。要使祭坛正常工作，需要搭建以下结构：

```
# # # # O # # # #
# O # # # # # O #
# # # # # # # # #
# # # # # # # # #
O # # # A # # # O
# # # # # # # # #
# # # # # # # # #
# O # # # # # O #
# # # # O # # # #
```

**结构搭建要点：**

- 🪵 **柱子材料：** 使用 **Stripped Spiritual Log）*，这种树通常可以在**热带草原**生物群系中找到。
- 📜 **顶层祝福：** 使用 **纸（Paper）** 对着顶层木头**右键**进行祝福。
- ✂️ **取消祝福：** 使用剪刀**右键**可以取消祝福状态。
- 🖐️ **完成合成：** 确认配方无误后，**空手 + Shift + 右键**祭坛完成合成。

### 2.3 弹幕指南

**弹幕（Danmaku）** 指的是 STG 游戏中常见的弹幕机制，即通过大量密集的弹体构成复杂攻击轨迹的表现形式。在本模组中，"弹幕"同样沿用这一概念。

#### 弹幕合成

玩家需要使用 **弹幕合成台（Danmaku Crafting Table）** 来合成弹幕。

**合成材料摆放：**

| 材料                                   | 数量 |
|--------------------------------------|:----:|
| 🎨 任意染料                              | ×4 |
| ⚙️ 弹幕核心（Danmaku Core）                | ×4 |
| 🔮 Power（灵力）                         | ×35 |
| 🔵 Point（点）                          | ×35 |
| 📝 弹幕创作模板 | ×1 |

#### 弹幕形态设置

**弹幕配方创建器** 是用于设置弹幕形态的关键工具，也是合成弹幕不可或缺的一部分。玩家可以通过**右键模板**，以点阵方式构建弹幕形态。

#### 弹幕强化

所有弹幕都可以在 **强化台（Strength Table）** 中进行升级。目前已定义的升级材料及效果如下：

| 升级材料 | 效果 |
|----------|------|
| 🗡️ 铁剑 | 提升弹幕伤害 |
| 🟩 粘液块 | 增加单次发射数量 |
| 🪶 速度羽毛（Speed Feather） | 提高弹幕射击速度 |
| 📜 符卡模板（Spell Card Template） | 设置弹幕轨迹 |

### 2.4 Fumo 玩偶

**Fumo（ふもふも）** 特指由日本 Gift 公司出品、基于同人社团 ANGELTYPE 角色设计的《东方Project》主题毛绒玩偶。

**核心特征：**
- 🧸 坐姿造型
- 😶 标志性的呆滞表情（ᗜˬᗜ）
- 🌸 柔软的毛绒触感
- 🎨 经授权制作的精致 Q 版形象

#### 获取方式

- 大多数 Fumo 可在**生存模式下通过价格较高的交易**获得。
- 玩家只能与 **Fumo 商人** 交易来获取 Fumo。
- Fumo 商人的交易内容**每天都会发生变化**。

#### Fumo 商人

使用 **Fumo 许可证（Fumo License）** 对村民右键，可将其转变为 Fumo 商人。

#### Fumo 特性

- 放置后，Fumo 会**自动朝向玩家**当前所在位置，支持 **16 个方向**的摆放。
- 右键点击 Fumo 方块时，会发出对应的 **Fumo 声音**。

### 2.5 角色伙伴

**角色伙伴（Role）** 是本模组中的随从类实体，其功能类似于 Touhou Little Maid 模组中的女仆单位。

#### 核心功能

| 功能 | 说明 |
|------|------|
| 🎒 背包 | 拥有独立的物品存储空间 |
| ⚔️ 战斗 | 可协助主人战斗 |
| 🛠️ 工作 | 可执行部分工作指令 |
| 💬 互动 | 支持对话等多种互动 |

#### 驯服方法

每个角色伙伴都需要一位主人。玩家可以通过**喂食蛋糕**来完成驯服并建立主从关系。

#### 召唤方法

在生存模式下，玩家可以在 **幻想乡祭坛** 中合成各类**东方 Project 角色卡**，以此召唤对应的角色伙伴。

#### 复活方法

当角色伙伴死亡时，会掉落 **角色档案（Role Archive）** 。玩家可以在 **幻想乡祭坛** 中摆放该物品，并在配方中**围绕两圈钻石**，以重新复活对应角色。

#### 操作说明

| 操作 | 效果 |
|------|------|
| 🖱️ 鼠标右键 | 触发日常对话 |
| Shift + 鼠标左键（空手） | 停止攻击目标 |
| Shift + 鼠标右键 | 打开背包 |

> 📖 [查看角色档案配方]

### 2.6 东方夜雀食堂

《东方夜雀食堂》是一款东方 Project 同人游戏，本 Mod 也将其作为一项独立玩法引入游戏中。

#### 系统概述

该系统主要添加了：
- 🥬 原作中的食材
- 🍳 料理
- 🍶 酒水
- 📖 烹饪配方
- 对 Minecraft 原版部分掉落物的调整

#### 食材来源

| 来源 | 说明 |
|------|------|
| 🌾 农作物 | 大部分食材拥有对应的农作物来源 |
| 📦 宝箱 | 部分种子可通过开启宝箱获得 |
| 🎣 钓鱼/采集 | 海产品需要钓鱼或采集获取 |

每种食物都带有不同的 **Tag**，不同 Tag 会赋予食物不同的效果。

#### 厨具系统

烹饪系统的厨具主要分为 **五类**，且均存在对应的**升级版本**：

| 厨具 | 用途 |
|------|------|
| 🥘 烹饪锅（Cooking Pot） | 基础烹饪 |
| 🔪 砧板（Cutting Board） | 食材处理 |
| 🍳 煎锅（Frying Pan） | 煎制 |
| 🥩 烤架（Grill） | 烧烤 |
| 🥟 蒸笼（Steamer） | 蒸制 |

> ⚠️ **黑暗料理：** 当配方输入不恰当或冲突词条时，可能会生成 **黑暗料理（Dark Cuisine）**。

> 💡 部分配方支持使用与本 Mod 兼容的其他模组物品进行等效替代。所有烹饪配方可通过本 Mod 的配方管理器或夜雀食堂维基查询。

> 📖 [查看各厨具配方及烹饪配方列表]

#### 酒水系统

大多数酒水可通过与**酒馆老板**交易获得。

**酒水特性：**
- 🍶 饮用后会提供不同的效果与增益
- 🔄 每日可交易的酒水种类可能发生变化
- ✅ **常驻酒水：** 绿茶、果味高球、果味酸酒、琪（Qi）始终会出现在售卖列表中

**酒馆老板转职：** 玩家可以手持**木桶**对村民右键，将其转职为酒馆老板。

## 3. 故事篇 — 探索记录

### 3.1 外界神社

**【探索记录 #01】**

我是在傍晚时分发现这座神社的。

它并不显眼。没有参道的灯，也没有成排的鸟居，只是在林间的一片空地上，突兀地存在着。地图上没有标注，周围也没有任何指示牌，仿佛从一开始就不打算被人找到。

但奇怪的是——这里并不像是废弃的。石阶被人清理过，苔藓只生长在边缘；手水舍中还有尚未完全蒸发的水迹；正殿前的赛钱箱没有上锁，木纹却被反复触摸得发亮。

这里……似乎仍有人居住。

---

**【探索记录 #02】**

我是在第二天清晨见到那位老者的。他从侧殿后方走出来的时候，我几乎没有察觉到他的脚步声。穿着朴素，动作缓慢，但并不迟钝。

他看了我一眼，没有惊讶，也没有询问。只是点了点头，然后继续做他原本正在做的事情——打扫落叶。

我试着与他交谈，他的话不多。回答也很简单，甚至可以说是刻意避开了某些问题。

> "这里一直都是这样吗？"
> "差不多吧。"
> "还有其他人吗？"
> "没有了。"
> "您一个人？"
> "嗯。"

对话到这里就结束了。他没有再继续说下去的意思。

---

**【探索记录 #03】**

我开始留意这座神社的细节。供台上的供品很简单，多是些普通的食物，偶尔也会出现一些不太常见的东西。香炉里的灰被整理得很整齐，说明香火从未真正断过。

偏殿里堆放着一些旧物。大多是破损的器具、褪色的布帛，还有一些已经无法辨认用途的物件。这些东西被保存得很好，不像是被遗弃，更像是被刻意留下。

我问老者这些东西的来历。他看了一眼，没有回答，只是说了一句：

> "该留的，就留着。"

---

**【探索记录 #04】**

这里的时间流动有些奇怪。不是停滞，也不是加速。更像是……被拉长了。

白天很安静，几乎听不到外界的声音。夜晚也没有灯火，只有偶尔吹过的风声。但无论什么时候来，神社都保持着一种"刚刚被人打理过"的状态。

我试着更早一些来到这里，结果发现老者已经在打扫。再晚一些离开，他依旧在。他似乎总是在这里。

---

**【探索记录 #05】**

我问他为什么要留在这里。他停下了手中的动作，想了一会儿。

> "总要有人在。"
> "为什么是您？"
> "刚好是我而已。"

他的语气很平静，像是在说一件再普通不过的事情。

我又问："如果没有人再来呢？"

他没有立刻回答。过了一会儿，他把扫帚靠在一旁，说：

> "那也一样。"

---

**【探索记录 #06】**

离开的时候，我回头看了一眼。神社依旧安静地立在那里。老者已经不在视线中，不知道是回到了哪一处偏殿。

但我知道——这里不会变成废墟。

至少，在那个人还在的时候。

记录到此为止。

---

### 3.2 迷你酒馆

**【记录：某处无名酒馆】**

这地方并不在任何标记之中。

我是在夜里误入这里的。原本只是沿着小路前行，远远看到一盏昏黄的灯，以为是普通的民居。走近才发现，那是一间规模很小的酒馆。门口没有招牌。窗子半掩着，里面透出暖色的光，还有断断续续的说话声。

推门进去时，铃声响了一下。

---

**【记录：店内观察】**

空间比想象中还要小。吧台占了大半，剩下的位置零散地摆着几张桌子。客人不多，也没有人喧哗。有人低声交谈，有人只是静静地喝着酒。气氛并不热闹，却也不冷清。

像是那种——只要你坐下，就会被默许留下来的地方。

---

**【记录：酒水】**

这里的酒很特别。菜单上写着一些难以理解的名字，配方也没有标注。我随意点了一杯，味道却出奇地复杂。并不是单纯的"好喝"，更像是……带着某种说不清的感觉。

有的让人精神一振，有的却让人不自觉地安静下来。

我试着询问这些酒的来历。得到的回答是：

> "只是些普通的配方而已。"

---

**【记录：店主】**

店主一直站在吧台后面。看不出具体年龄。说话的语气很随意，但总让人觉得他知道得比表现出来的更多。

我提到一些传闻时，他会停顿一瞬，然后笑一笑，换个话题。

> "这些名字听起来不像是这边会有的东西。"
> "你去过很多地方吗？"
> "算是吧。"
> "那这些酒呢？"
> "也是路上学来的。"

他说得很轻描淡写。但我并不确定那是不是实话。

---

**【记录：细节】**

墙上挂着一些装饰。有些是普通的酒具，也有些看起来并不像是这里会出现的东西。其中一件我试着多看了几眼。店主注意到了。

> "别太在意那些。只是些旧东西。"

---

**【记录：离开】**

我没有待太久。离开时，店主没有挽留，只是点了点头，像是对每一个离开的人都如此。门关上的那一刻，灯光被隔在了身后。再回头看时——那盏灯似乎比刚才更暗了一些。

我没有再进去确认。

**【补记】**

后来我试着再次寻找这个地方。

却没有找到。

---

### 3.3 废弃祭坛

**【探索记录：未标记遗迹】**

我是在一片几乎没有人迹的区域发现它的。最初只是一段异常平整的地面。与周围杂乱的环境相比，这里显得过于规整。顺着痕迹继续向前，便看到了这座祭坛。

---

**【结构观察】**

这显然曾被人为建造。石材的排列带有明显的规律，中心区域留有用于放置物品的位置。周围的构造也并非随意堆砌，更像是某种仪式用途的结构。

但现在——一切都已经被遗弃。灰尘覆盖在表面，几乎看不出原本的颜色。藤蔓沿着边缘蔓延，将部分结构牢牢缠住。有些地方甚至已经出现了轻微的破损。

这里已经很久没有被使用过了。

---

**【残留物】**

祭坛旁仍然留有一个箱子。并未上锁。里面的物品不算整齐，但也没有被完全洗劫。一些材料已经腐坏或失去作用，但仍有一部分可以辨认，甚至仍可使用。

这些东西似乎是在匆忙中被留下的。不像是刻意储存，更像是——来不及带走。

---

**【初步判断】**

从结构和残留来看，这座祭坛原本应当具备某种功能。只是现在，它已经失效了。

我尝试将部分材料放回原位。没有反应。也许缺少某些关键步骤，又或者——需要某种特定的条件。

---

**【记录】**

离开之前，我再次确认了周围环境。没有其他明显的痕迹。没有脚印，也没有近期活动的迹象。

这里就这样被遗忘着。

---

**【结论】**

这座祭坛或许仍有被重新激活的可能。但目前为止，我没有足够的信息去完成它。

我决定暂时离开。

（记录中断）

---

### 3.4 废弃鸟居

**【简要记录】**

在一片空地中发现了一座孤立的鸟居。

结构已经老旧，上面布满了藤蔓与风化的痕迹。原本的颜色几乎被掩盖，只剩下斑驳的轮廓。

周围没有神社，也没有道路。甚至看不出这里曾有过其他建筑的迹象。

它就这样单独立在这里。

像是被遗留下来的——某种边界。

---

### 3.5 樱冢

**【探索记录】**

我在一处樱冢下停留了片刻。

这里比周围安静许多。风声经过时，会带起细碎的花瓣，却很快又归于平静。地面没有明显被打扰的痕迹，看起来已经许久无人来过。

但这里并不"空"。

空气中隐约残留着一丝灵力波动，微弱，却稳定地存在着。不像是刚刚产生的，更像是某种长久以来积累下来的痕迹。

我试着在周围寻找来源。没有发现明显的装置或结构，也没有可辨认的仪式痕迹。这些灵力似乎散落在环境之中——附着在土壤、树根，甚至落下的花瓣之间。

也许，这并不是某个"正在发生"的现象。而是某些事物曾在这里存在过。

目前无法确认其具体成因，记录在此，留待后续调查。

---

### 3.6 竹林烧烤摊

**【探索记录】**

我是在迷路时发现这里的。

竹林深处本不该有人停留太久。方向很容易混乱，路径也不稳定。但就在这样的地方，却出现了一处小型的烧烤摊。

结构很简单。木制的架子、炭火用具，还有摆放整齐的食材。一切看起来都在正常使用之中。

问题是——这里没有人。

没有脚步声，也没有离开的痕迹。炭火已经熄灭，但仍残留着不久前使用过的气味。桌面上的食材十分新鲜，像是刚刚准备好。

我没有停留太久。

---

**【补充记录】**

之后的几天里，我试着在夜晚再次靠近这片区域。远处能够看到微弱的火光，像是有人在点燃炭火。

但当我真正接近时——那里依旧空无一人。

摊位保持着同样的状态，仿佛每一晚都会"照常营业"。

目前无法确认其运作方式。

---

### 3.7 竹林小屋

**【探索记录】**

在竹林深处发现了一间小屋。

远远望去，屋内透出微弱的光。在这片容易迷失方向的环境中，这样的光源显得格外突兀。小屋外侧有一方水池。水面平静，其上生长着几片荷叶，状态良好，像是有人细心照料过。但周围并没有明确的活动痕迹。

通往这里的路径已经变得模糊。落叶与新生的植被覆盖了一切，几乎无法辨认出原本的道路。

然而，这里并不显得荒废。无论是水池中的植物，还是屋内持续存在的灯光，都在维持着一种微妙的"生气"。

我没有进入屋内。仅在外围进行观察后离开。

这里似乎依靠着某种方式，被持续地维持着。

---

### 3.8 地狱春泉

**【探索记录】**

在一处低洼地带发现了一片温泉。

水面持续冒着热气，温度明显高于周围环境。泉水本身并不浑浊，反而显得异常清澈。起初看起来只是普通的天然温泉。

直到我注意到周围的摆设。

泉边零散地放置着几支蜡烛。有些已经燃尽，只剩下凝固的蜡痕；也有几支仍在缓慢燃烧。火光并不稳定，在水汽的干扰下微微晃动，却始终没有熄灭。

这里没有发现任何人的踪迹。

这些蜡烛不像是随意放置，更像是……某种刻意留下的痕迹。

我没有继续停留。
