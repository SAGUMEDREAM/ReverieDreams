图层

模式

高度工具

笔刷半径 2

范围 0–512，可直接输入精确值（大半径群系涂抹更快）。

笔刷强度 1

强度影响高度抬升/降低幅度，以及平滑和压平的渐变强度。

3D 起伏显示 1× XZ 1×

仅影响 3D 预览，不改地图数据，也不影响保存到游戏的地图。垂直夸张自动模式会按地图宽度和高度差选择倍数；横向缩放只改变 XZ 预览比例，1× 为真实比例。标准/高/超高是整图降采样预览；1:1 方块只渲染视图中心 512×512 的完整方块网格，随视角移动，缩放下限 2×、上限 100×，整图缩放请切回降采样模式。

3D 实际方块

关闭坡度平滑，3D 顶面按高度图逐格显示，并在高度差处生成竖直方块侧面。

地形选区 无

选区模式拖动框选；Ctrl+C / Ctrl+V 复制粘贴，粘贴以当前鼠标格为左上角。模板保存在浏览器本地。

当前地图群系调色板 0

这里保持地图索引稳定；已有群系点击后用作群系笔刷。候选群系不会自动追加。

候选群系库 0

按“幻想乡群系 / 原版群系 / 其他模组群系”分组；点击候选才会追加到当前地图调色板，最多 256 项且不重排旧索引。

0 为硬边界；过渡用确定性 hash 在边界附近混样。编辑器逐格预览，游戏按 4×4 quart 采样，客户端“生物群系混合”会进一步柔化颜色。

地下编辑

切片 Y 控制 2D/3D 预览；笔刷 Y 范围控制一次落笔覆盖的垂直范围（单次最多 256 格）。3D 地下模式下 Shift+滚轮调整切片 Y。

地表调色板

方块物品栏

单击方块选中并预览，双击可直接装备到地表；方块会加入当前地图的 surface_palette。

方块属性 默认

属性会写入 blockstate 字符串；未修改时使用方块默认状态。保存后 Java 生成器按完整状态放置。

结构 / 装饰物

进入结构 tab 后地形笔刷暂停：拖动鼠标框选结构，Ctrl/Shift 追加选择；点击锚点行可编辑坐标或移动。

选中结构

坐标/变换字段修改主结构；多选时请用“移动模式”整体移动。3D 视图可直接拖动锚点/结构框移动 X/Z，拖绿色圆环旋转 90°，拖蓝色竖杆调整 Y，拖橙色方块缩放（0.25–4）；Esc 取消。旋转、镜像和缩放会进入撤销历史。

装饰物 / 树林

装饰物使用原版树 / 花草 / 岩石结构模板；森林笔刷按当前笔刷半径随机种树，支持撤销。

光照

仅影响 3D 视图的太阳方向；低高度角会偏暖，高高度角接近正午白光。阴影关闭可提升大地图性能。

快捷键

T / D / V：地形 / 结构 / 光照
E / M：方块物品栏 / 地图信息
J：森林笔刷
方块页：全部方块物品栏
方向键：移动 3D 视角 / 2D 视口
1 / 2 / 3 切换图层
B / R / I：笔刷 / 矩形 / 吸管
X 挖空；F 适应地图
[ / ] 笔刷大小；G 网格；W 水面
2D：滚轮缩放；中键/右键拖动平移
3D：左键编辑；右键拖动旋转；中键拖动平移；滚轮缩放
Esc 退出结构放置
Ctrl+Z / Ctrl+Y 撤销重做
Ctrl+S 保存
