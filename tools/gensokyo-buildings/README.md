# 幻想乡建筑选址与原稿转换

本工具用于 2026-11-19 的红魔馆、博丽神社及后山连接工程。交付数据与平面预览位于 `../../data/shrine-mansion-20261119/`。正式地图版本为 revision25，现有游戏存档没有被本工具修改。

## 结构资产和配置生成

最终结构统一位于 `common/src/main/resources/data/reverie_dreams/structure/gensokyo/*.nbt`。
NBT 内的 `reverie_structure_metadata` 保存版本、功能点与兼容哈希，红魔馆的 `reverie_adventure` 保存奖励和遭遇配置。
这两个 compound 是结构的附加作者数据，原版结构读取仍使用 size、palette、blocks、entities。
Fabric datagen 只从最终 NBT 导出 Codec 配置 JSON，运行时通过 BuiltInRegistryProviders 重载。
内容指纹覆盖建筑与配置。修改后需要更新 content_version 并执行 datagen，旧存档仍走已有结构升级流程。
原始 Litematic 及导入前文件已在本地迁移备份中留存，作者考证工具可读取用户原稿 E:/Download/红魔馆.litematic。

## 工具职责

- `survey.py`：只读解析原稿、反向框选和逐格位压缩；产生分析数据。
- `site_layout.py plan`：读最新正式地图，在既有道路接口与真实地形间选线；输出全宽候选与纵断面。
- `site_layout.py prepare`：先按SHA备份，制作独立工作检查点。保护现有道路核心、桥梁、水体、群系和地下覆盖。已有路肩只在23个接头列改为通行核心。
- `site_layout.py publish`：通过编辑器保存会话提交并同步到运行资源；必须先有模板对照及原生测试PASS。包含基准revision、源/工作SHA和在线用户检查，不能重复提交历史工程。
- `site_layout.py verify`：核对完整变动集合、源/runtime逐格一致、备份、原道路核心与三处新路连接。
- `validate_template.py`：流式比较实际datagen NBT与原稿，逐块核对所有状态、方块实体及普通实体；检查院门5格宽、5格高的净空。
- `render_plan.py`：真正北朝上的地理平面、原稿方块俯视投影和自包含SVG交互预览，不冒称实机航拍。
- `native/`：一次性原生 Fabric 客户端探针，验证真实地图生成、完整锚点安装、门口双向行走、道路铺装和装饰后的净空。

原稿是用户提供的参考资产，本轮保留其外观，未新画贴图、改模型或声称用户已验收。根目录AGENTS约束适用于全部复现；运行与构建放本任务 E:/Temp 临时目录，结束清理，不为试跑生成另一套安装包。
