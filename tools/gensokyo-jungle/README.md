# 幻想乡丛林

`reverie_dreams:gensokyo_jungle` 由 `RDBuiltinBiomes.bootstrap → GensokyoForestBootstrap.biomes` 注册，继承温带森林基础地物，以六种独立轮廓的丛林树替换树层，不继承原版竹子、西瓜或热带动物生成层。不会加入主世界自然群系分布；原版丛林行为不修改。

| 树形 | 高度范围 | 选择权重 |
| --- | --- | --- |
| 板根高冠 `jungle_canopy` | 26–36 | 10% |
| 低位分叉 `jungle_forked` | 18–26 | 22% |
| 多层树冠 `jungle_tiered` | 20–30 | 18% |
| 偏冠斜生 `jungle_leaning` | 14–22 | 16% |
| 宽展伞冠 `jungle_spreading` | 12–18 | 16% |
| 林下幼树 `jungle_young` | 8–12 | 18% |

高度包含树冠；权重是选树概率，实际放置还受地形、空间和道路保护影响。每类内部仍有高度、枝向和冠幅变化。使用原版丛林木/树叶，灌丛混入橡木，无新方块或贴图。草色 `#709b50`、叶色 `#4d7e3b`。

林下复用四种尺度的低叶丛、分枝灌木、小型树丛和花叶地表斑块，按共用栖息地噪声聚集并留空地。蕨类、少量铃兰、树下落叶、苔毯与褐菇按既有光照/生存与树冠条件落地。苔石的三种尺度候选频率分别每12/64/768区块一次，巨石为少量焦点。藤蔓每区块2次小范围尝试，只依附木/叶，单次最多20块，离地至少3格；倒木每24区块一次尝试，复用完整支撑/水/道路保护。旧森林的倒木预览限制保留。

地图迁移工具 `integrate-map.py` 使用现有编辑器修订事务和同步API。它先审计原版三种丛林占用，仅在普通/稀疏丛林为0、原版竹林有内容时，把有内容的调色板槽改为专用丛林；若地图情形改变则先拒绝，避免静默漏迁移。原始图层索引和其他地图内容不变，迷途竹林保留。不写 provider 管理的维度JSON/群系清单，后续实际 Fabric datagen 负责生成它们。

`sync-generated.py <Fabric隔离输出目录>` 只选择本任务实际provider输出，检查并行修改、语言保留及HashCache归属后逐文件原样复制，禁止用它编造或补丁JSON。修改世界生成/标签/翻译后必须运行实际Fabric datagen；禁止调用旧预览导出器把JSON写入生成树。

`ExportJunglePreview.java` 只导出几何证据，不导出游戏数据；`render-preview.py` 画出六树形、枝干和地图替换范围。这些是离线示意图，不是实机截图或用户验收。验证与精简证据位置：`build/gensokyo-jungle-review`。开发不额外交付安装包，正式 `build/dist` 状态另行报告。

在允许作弊的世界使用 `/locate biome reverie_dreams:gensokyo_jungle` 寻找区域，或在空地使用 `/place feature reverie_dreams:gensokyo/jungle_canopy ~ ~ ~` 等命令预览单棵树。大树需要足够平整、无障碍的完整空间。

`GensokyoBiomeSource` 解码旧维度列表时，仅把固定幻想乡地图中已被作者替换成新丛林、且旧列表仍为原版三种丛林之一的同索引槽升级。保留其他地图、自定义群系与全部索引位置，使旧世界重启后的新生成区块也能使用新丛林。旧存档已经生成的区块不会自动改树或重刷群系，须在新世界/新生成区块查看；不直接修改用户存档。
