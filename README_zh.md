# 梦隐的幻想乡（Gensokyo: Reverie of Lost Dreams）

*被遗忘的梦并不会消逝，只是漂向了别处——幻想乡并非只有一个，每个人心中都有属于自己的幻想乡。*

这是一个以东方 Project 为灵感创作的 Minecraft 模组，包含弹幕战斗、全新维度、钓鱼、烹饪以及自定义内容生态系统。

## 兼容性

| 平台               | 支持情况 |
|------------------| ---------------------------- |
| Fabric           | 支持 |
| NeoForge         | 支持 |
| Polymer（服务端）     | 仅支持 Fabric |

## 主要特色

- 新钓鱼内容
- 弹幕战斗系统
- 东方原作和二创中的生物实体
- 全东方STG作的符卡还原
- 自定义工作台与生产加工方块
- 受《东方夜雀食堂》启发的烹饪系统
- 内置配方浏览器，无需安装 JEI/EMI
- 可招募的东方角色伙伴
- 用于推进游戏进程的合成祭坛
- 幻想乡维度、梦境世界维度和月球维度

## 鸣谢与版权说明

本项目为非官方同人作品，与原作权利方不存在官方关联。

本项目的创作灵感来源于《东方 Project》（上海爱丽丝幻乐团，ZUN）及《东方夜雀食堂》（Touhou: Mystia's Izakaya）。

本项目中受《东方夜雀食堂》启发的视觉资源均经过独立重绘与重新制作，部分玩法机制及系统也参考原作进行了重新实现。

除另有说明外，本项目中的各项功能实现及重绘资源均为独立创作。
